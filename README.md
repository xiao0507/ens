# CET6 六级预测模拟卷 · 离线网页应用

一个**纯前端、零后端、零 API Key** 的大学英语六级（CET-6）模拟预测卷应用。题库与出题逻辑全部内置，打开网页即可生成 **第 1～50 套**完整模拟卷，手机 / 电脑自适应，答案默认收起、点击展开三段式解析。

> 适合直接部署到 **GitHub Pages**，免费拿到一个属于你自己的独立网址；网址与扣子无关，长期可访问。

---

## ✨ 功能特性

- **无需任何 API / Key / 服务器**：纯 HTML + CSS + JavaScript。
- **固定四大板块**：写作（15%）、听力理解（35%，每套 25 题）、阅读理解（35%）、翻译（15%）。
- **指令式交互**：
  - `生成第3套` → 整套试卷，全部答案隐藏
  - `只出翻译题` / `只看阅读` → 单独练习某一题型
  - `展开阅读答案` → 展开对应大题
  - `重新生成这套题` → 同套号换一批素材组合 / 选项顺序
- **答案三段式解析**：✅ 文章重点　✅ 句式重点（长难句拆解）　✅ 词汇重点（音标 + 释义）。
- **移动端友好**：短句分段、大按钮、自适应宽度；手机浏览器可「添加到主屏幕」当 App 用。
- **听力练习**：提供可展开的「录音文字稿」模拟听力，课堂可由教师朗读或自行配音频。

## 🖥️ 本地使用

直接双击 `index.html` 即可使用，无需安装、无需联网。

可选校验（需要 [Node.js](https://nodejs.org)）：

```bash
node scripts/validate.js   # 结构 / 答案合法性 / 1–50 套组卷
node scripts/smoke.js      # 页面渲染冒烟测试
```

## 🚀 部署为独立网址（GitHub Pages，免费，约 3 分钟）

### 第 1 步：新建公开仓库
1. 登录 [GitHub](https://github.com)，右上角 **＋ → New repository**。
2. 仓库名用英文，例如 `cet6-paper`（这个名字会出现在网址里）。
3. 选择 **Public**（免费版 Pages 需要公开仓库）。
4. **不要**勾选 “Add a README file”，点击 **Create repository**。

### 第 2 步：上传文件
1. 在空仓库页面点 **uploading an existing file**（或 **Add file → Upload files**）。
2. 把本压缩包**解压后的全部文件**拖进去——注意要让 `index.html` 直接出现在仓库**最外层**，不要再套一层文件夹。
3. 拉到底部点 **Commit changes**。

### 第 3 步：开启 Pages
1. 进入仓库 **Settings（设置）→ Pages**（左侧菜单）。
2. **Source / Build and deployment** 选 **Deploy from a branch**。
3. **Branch** 选 `main`，右边目录选 **`/ (root)`**，点 **Save**。
4. 等 1～2 分钟刷新该页，顶部会出现你的独立网址：

```text
https://<你的用户名>.github.io/<仓库名>/
```

把它发到手机或电脑浏览器即可使用，也可以分享给同学。以后修改任意文件并 Commit，网址会在 1～2 分钟内自动更新。

### 📱 在手机上当 App 用
用手机浏览器（Safari / Chrome / Edge）打开上面的网址 → 浏览器菜单选 **“添加到主屏幕 / 安装应用”**，桌面就会出现图标，点开全屏运行。

## 🧩 出题机制说明（重要）

本应用**不联网调用大模型**，题目来自内置题库，再由 `js/generator.js` 用「套号 + 确定性算法」动态组卷：

- 同一套号可稳定复现；不同套号 / 点击「重新生成」会切换素材组合、听力与阅读的**选项顺序**。
- 题库为**有限素材池**（写作 / 翻译各 12 篇、听力 10 组、选词填空 8 篇、长篇匹配 6 篇、仔细阅读 12 篇），不同套号间可能出现素材复用，属离线版正常现象。
- 想增加不重复题量：按 [`docs/data-schema.md`](docs/data-schema.md) 向 `js/data/` 追加题目，再运行 `node scripts/validate.js` 校验即可，无需改动其它代码。

## 📝 指令速查

| 输入 | 结果 |
| --- | --- |
| `生成第N套` / `第N套` | 整套试卷（1≤N≤50），答案隐藏 |
| `只看写作/听力/阅读/翻译` | 只生成对应题型 |
| `生成第10套，只出翻译题` | 指定套号的单题型 |
| `展开XX答案` | 展开对应大题答案与解析 |
| `重新生成这套题` | 同套号换组合 / 选项顺序 |

## ❓ 常见问题

- **打开 Pages 网址显示 404？** 多半是 `index.html` 没在仓库根目录（被多套了一层文件夹），或 Pages 还没生效，稍等 1–2 分钟。
- **样式乱了 / 题目不显示？** 确认 `css`、`js` 文件夹和 `index.html` 一起上传、目录结构保持不变；仓库里保留了 `.nojekyll`。
- **需要联网 / 花钱吗？** 都不需要。纯静态，GitHub Pages 免费。
- **能放多少套？** 界面支持第 1～50 套；素材由内置题库组合，扩充方法见上。
